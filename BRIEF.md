Multiple Chat Rooms

Buatlah sebuah aplikasi berbasis desktop yang digunakan untuk menyediakan layanan

chatting. Pada aplikasi tersebut seorang pengguna dapat membuat room baru atau memilih

room yang tersedia untuk dapat tergabung ke ruang chat. Ruang chat dapat digunakan untuk

multiple user (memungkinkan lebih dari 2 orang). Setelah bergabung ke dalam ruang chat,

para pengguna tersebut dapat berkomunikasi dengan mengirimkan pesan teks. Pesan teks

tersebut secara otomatis akan muncul di semua pengguna yang berada di ruang chat

tersebut.

Fitur dasar dari aplikasi chat:

• Pengguna dapat masuk ke dalam sistem (sebagai identitas diri)

• Pengguna dapat membuat ruang chat baru.

• Pengguna dapat melihat semua ruang yang tersedia beserta informasi ruangan.

• Pengguna dapat memasuki ruang chat tertentu.

• Di dalam ruang chat, pengguna dapat mengetahui siapa pengguna lain yang berada

di ruang tersebut. Dan memberikan pemberitahuan apabila terdapat pengguna lain

yang tergabung.

• Di dalam ruang chat, setiap pengguna dapat mengirimkan pesan teks yang akan

diterima oleh pengguna lain di ruang tersebut.

• Chat yang ditampilkan dilayar harus dapat dibedakan antara pengirim atau penerima

pesan.

• Pengguna dapat keluar dari ruang chat (dan juga memberikan pemberitahuan ke

pengguna lain jika ada yang keluar)

• Pemilik ruang juga dapat menutup ruang dan menghapus dari daftar ruang. (secara

otomatis pengguna lain akan terputus dan Kembali ke halaman utama)

• Pemilik ruang dapat mengeluarkan pengguna yang tidak diinginkan di ruang tersebut.

Contoh fitur tambahan (opsional):

• Seluruh data dapat terkoneksi dan tersimpan pada basis data.

• Dapat mengirimkan gambar / file pada ruang chat.

• Dll.

Instruksi pengerjaan:

1. Pembuatan aplikasi ini mengharuskan anda untuk menggunakan socket

programming sebagai sarana komunikasinya.

2. Aplikasi terdiri dari minimal 2 aplikasi yaitu aplikasi server dan aplikasi klien. Untuk

aplikasi klien, diharuskan menggunakan tampilan GUI.

3. Aplikasi dibuat secara berkelompok sebanyak 3 orang.

4. Aplikasi yang dibangun dibebaskan menggunakan Bahasa pemrograman Java /

Python. (dengan konsekuensi untuk python belum/tidak diajarkan di kuliah wajib).

5. Aplikasi yang dibangun harus dapat berjalan di komputer yang berbeda pada jaringan

yang sama.

6. Kalian dibebaskan untuk berkreasi dan menambahkan fitur tambahan lain yang

menarik tetapi masih dalam ranah topik yang sama.
